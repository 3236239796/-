# NULL//ASCENT — 游戏设计

## 核心定位
第三人称俯视 3D 动作 Roguelite。玩家扮演“裂隙行者”，深入一座被异界侵蚀的巨构设施，击破五个战区并摧毁最终核心。目标不是无脑站桩刷怪，而是通过瞄准、走位、闪避时机、技能资源管理和构筑协同掌控战场。

## 体验支柱
1. **可读而有压力的战斗**：敌人攻击有明确前摇、方向和范围；危险来自位置选择而非随机扣血。
2. **每局构筑有变化**：升级不是单纯堆数值。武器模块、相位技能、遗物之间有标签协同与可感知的组合变化。
3. **逐层升级的敌人生态**：追猎者逼迫移动，狙击者控制空间，重装者封锁路线，Boss 用阶段机制改变战场。
4. **高级工业科幻美术**：暗色陶瓷、拉丝金属、磨损边缘、半透明能量、受控的青绿/琥珀/猩红发光，电影式构图与真实光照。禁止像素风、幼稚卡通、单色几何占位。
5. **视听反馈服务战斗**：命中、暴击、破盾、冲刺、Boss 前摇均有独特声音和视觉反馈；音乐采用原创合成氛围层，不依赖外部服务。

## 一局流程
- 主菜单选择“开始远征”。
- 进入战区：清理敌群、收集回响碎片、完成战区目标。
- 获得经验后暂停战斗，三选一强化。
- 每个战区末出现精英或守门者；第五战区为最终 Boss。
- 胜利后结算击杀、用时、最高连击、构筑和永久记录；失败也保存本局最佳进度。
- 可重新开始，永久记录只保存统计，不用付费/抽卡机制。

## 操作
- WASD：移动；鼠标：瞄准；鼠标左键：主武器；Space/Shift：相位冲刺；E：裂隙脉冲；P/Esc：暂停。
- 冲刺具有短暂无敌帧，方向由移动输入决定；无方向时朝瞄准方向冲刺。
- 主武器手动射击，按住可连续开火。特殊能力消耗充能，击杀和收集回响可恢复。

## 战斗系统
- 玩家拥有生命、护盾、冲刺冷却、技能充能、伤害、射速、暴击、穿透、弹射等属性。
- 敌人：Ravager（近战追击）、Stalker（快速突进）、Arbalist（远程压制）、Bulwark（重装区域封锁）。
- Boss：The Choir，三阶段：召唤回声体、环形弹幕与地面裂隙、低生命值狂暴冲锋。
- 敌方危险区先显示，再结算伤害。弹幕与玩家碰撞可测试、可规避。
- 掉落：经验回响、治疗核心、相位碎片。掉落不自动瞬移，要求玩家承担路线选择。

## 构筑
强化按 Offense / Mobility / Defense / Anomaly 四类组织，具有稀有度、等级上限与协同标签。
- Prism：主武器分裂、穿透、回旋。
- Phase：冲刺留下伤害轨迹、冲刺后短暂增伤。
- Echo：命中回声、连锁闪电、击杀爆裂。
- Aegis：护盾、格挡窗口、低生命减伤。
三件同标签模块触发套装效果；至少两条可形成明显差异的构筑路线。

## 视觉规范
- 3D 实时渲染，WebGPU 优先，WebGL2 回退。
- PBR 金属/粗糙度材质、阴影、环境光、Bloom、色调映射、抗锯齿。
- 场景采用大型工业圆形平台、分层高差、环形结构、发光导轨、残骸、晶体和雾化远景。
- 玩家/敌人使用组合网格与细节层，不允许只有球体/方块作为最终角色。
- 特效必须有生命周期、性能上限和质量档位。

## 音频
音乐采用 SRG774 的 CC0《Dark Sci-Fi Audio Pack》：菜单/低威胁使用 Airy，探索使用 Sector，战斗切换 Urgent，Boss 叠加 Pulse，胜利播放 Victory，失败播放 Transmission。音乐按场景异步加载并交叉淡入淡出，避免启动时一次性下载全部曲目。Web Audio API 继续负责低频环境 Drone、武器瞬态、金属命中、护盾破裂、冲刺噪声和 Boss 提示。音量、音乐开关与音效开关独立控制。所有第三方音频必须有明确的可再分发许可并记录来源。

## 完成定义
- 可以从菜单开始完整一局，至少包含五个战区和最终 Boss。
- 战斗、升级、构筑、胜败、重开和永久统计均可用。
- 所有关键输入有反馈，敌人攻击有预警且可躲避。
- WebGPU 路径与 WebGL2 回退都能初始化；失败有可理解的状态提示。
- 生产构建、单元测试、浏览器烟雾测试通过。
- 浏览器控制台无未处理异常；不同分辨率可玩。
- 视觉和玩法通过独立反方审查；没有以“原型能打开”冒充完成。
